更新履歴

RocketWhisper Windows版の各バージョンで追加された機能・改善点・不具合修正の一覧です。

v2.0.1 - 2026年10月6日

  • 【不具合修正】休止状態・スリープからの復帰後に音声認識が使えなくなる問題を修正 — 一部の GPU（AMD など）で、復帰後はアプリを再起動するまで認識できなくなることがありました。復帰時と GPU エラーの発生時にアプリが自動で再起動し、GPU を初期化し直します。メイン画面の文章はそのまま引き継がれます。
  • 【不具合修正】Groq の AI 処理が動かない問題を修正 — Groq 側で LLaMA 3.3 70B / 3.1 8B が2026年8月16日に提供終了したため、後継の GPT-OSS 120B / 20B に切り替えました。
  • 【不具合修正】Claude Sonnet 5 / Opus 5 で AI 処理の結果が空になることがある問題を修正
  • 【不具合修正】認識に失敗したとき、前回の認識結果が自動貼り付けや AI コマンドに使われてしまう問題を修正
  • 【AI処理】対応モデルを更新 — OpenAI GPT-6.1 Sol / GPT-6 Luna、Claude Sonnet 5.5 / Opus 5.5、Gemini 3.8 Flash（既定）。以前のモデルを選んでいた場合は、同じ価格帯の後継モデルへ自動で引き継ぎます。
  • 【サポート】診断ログを追加 — 不具合のお問い合わせの際に原因を調べやすくなりました（保存先 %APPDATA%\RocketWhisper\logs。音声・認識した文章・APIキーは記録しません）。

v2.0.0 - 2026年9月6日

  • 【認識精度】VAD（音声区間検出）によるハルシネーション抑制 — Silero VADを搭載し、無音や環境音だけの区間を認識前に除外。無音の録音から架空の文章が生成される現象を入口で防ぎます（設定「モデル・言語」タブでオン/オフ可、既定オン）。
  • 【GPU対応】CUDA 12系ランタイムを追加 — CUDA Toolkit 12系をインストール済みのNVIDIA環境でもCUDA加速が使えます（CUDA加速にはNVIDIA CUDA Toolkit 13または12のインストールが必要です。詳しくはヘルプのトラブルシューティング）。Vulkan（NVIDIA/AMD/Intel）は従来通り。バージョン情報画面で使用中の認識エンジンを確認できます。
  • 【AI処理】対応モデルを最新世代に更新 — OpenAI GPT-5.6（Terra/Luna/Sol）、Anthropic Claude Sonnet 5 / Haiku 4.5 / Opus 5、Google Gemini 3.7 Flash ほかに刷新。旧モデルを設定していた場合は自動的に既定モデルへ切り替わります。
  • 【配布】インストーラにコード署名を付与 — 発行元「Mojosoft Co., Ltd.」の電子署名付きで配布します。
  • 【内部】音声認識エンジンを Whisper.net 1.9.1 に更新 — 未使用コンポーネントを整理し、インストールサイズを削減しました。

v1.2.4 - 2026年4月2日

  • 【安定性改善】GPU障害からの自動回復 — 休止状態復帰後にGPUドライバ（CUDA/Vulkan）がクラッシュした場合、Whisperモデルを自動で再読み込みして復帰します。
  • 【安定性改善】音声認識タイムアウト — GPUハング時に無限待機しなくなりました。タイムアウト検出後にモデルを自動再読み込みします。
  • 【安定性改善】電源復帰時のリトライ — ドライバ復帰に時間がかかる場合も最大3回リトライして確実に再初期化します。

v1.2.3 - 2026年3月19日

  • 変換速度表示 — 音声認識完了時にステータスバーに処理時間とRTF（リアルタイムファクター）を表示。パフォーマンスを一目で確認できます。

v1.2.2 - 2026年3月16日

  • 【安定性改善】休止状態/スリープ復帰後の自動回復 — 休止状態からの復帰時にWhisperモデルとオーディオデバイスを自動的に再初期化。CUDA GPUメモリの無効化やオーディオドライバの不整合を自動検出・復旧します。
  • 【堅牢性向上】エラー発生時の安全な終了 — 予期しないエラーが発生した際にプロセスが応答不能になる問題を改善。エラーメッセージを表示して安全に終了します。
  • 【堅牢性向上】オーディオデバイス列挙の例外保護 — マイクデバイスの列挙時にドライバエラーが発生してもアプリがクラッシュしない設計に改善。

v1.2.1 - 2026年2月26日

  • USBマイクのホットプラグ検出 — マイクの接続・切断をリアルタイムに検出し、設定画面のデバイス一覧を自動更新。
  • 動画ファイルの文字起こし対応 — MP4/MKV/AVI/MOV/WebMなどの動画ファイルからFFmpegで音声を抽出して直接文字起こし。

v1.2.0 - 2026年2月11日

  • カスタム指示機能 — 専用ホットキーで特定のAI指示を即座に実行。テキスト翻訳・要約・校正などを音声入力なしで高速処理。

v1.1.2 - 2026年2月5日

  • 【不具合修正】右Altキーが押されたままの状態になることがある問題を修正（再発分）
  • 【改善】通知音を変更 — 録音開始・停止の通知音を、Windows 標準の控えめな音に変更しました。

v1.1.1 - 2026年2月3日

  • 【新機能】録音開始・停止の通知音 — 録音の開始と停止を音でお知らせします（設定でオン/オフ可）。
  • 【改善】録音中インジケーターを小型化
  • 【不具合修正】右Altキーが押されたままの状態になることがある問題を修正 — 右Alt 押し続けモードのキー処理を見直しました。
  • 【改善】録音できないときは右Altキーを通常どおり動作させるように変更 — モデルの読み込み中や認識処理中など、録音を開始できないときは右Altキーをそのまま他のアプリに渡します。

v1.0.5 - 2026年2月2日

  • 【新機能】右Alt 押し続けモード — 右Altキーを押している間だけ録音します。素早く2回押すと、もう一度押すまで録音を続けます。
  • 【新機能】AIコマンドモード — テキストを選択して専用ホットキーを押し、音声で指示すると、選択したテキストを AI が指示どおりに処理します。
  • 【新機能】音声検索 — 「〇〇について調べて」などと話すと、ブラウザで Google 検索を実行します。
  • 【変更】既定のホットキーを変更 — 録音は「右Alt（押し続け）」、AIコマンドは「Ctrl + Space」になりました。
  • 【変更】「AI整形」の名称を「AI処理」に変更

v1.0.2

  • 【GPU対応】NVIDIA GPU による CUDA 加速に対応 — CUDA 加速を使うには NVIDIA CUDA Toolkit のインストールが必要です（現在の要件はヘルプのトラブルシューティングを参照）。
  • 【改善】既定のモデルを large-v3-turbo に変更 — 高い精度のまま、より高速に認識します。
  • 【改善】モデルのダウンロード再開 — 途中で止まったモデルのダウンロードを検出し、続きから再開できるようになりました。
  • 【AI処理】Anthropic Claude のモデルを 4.5 世代に更新
  • 【不具合修正】自動貼り付け時のクリップボードに関する不具合を修正
  • 【改善】誤認識修正ルール機能を改善
  • 【不具合修正】誤認識修正ルールの画面でエラーが発生する問題を修正
