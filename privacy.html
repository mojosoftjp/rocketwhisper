プライバシーポリシー

RocketWhisperは、あなたのプライバシーを最優先に設計されています。

最終更新日: 2026年10月24日

本プライバシーポリシーは、RocketWhisper（以下「本アプリ」）におけるデータの取り扱いについて説明します。Mojosoft Co., Ltd.（以下「当社」）は、ユーザーのプライバシー保護を最優先に考え、本アプリを設計・開発しています。

1. 基本方針

音声認識はお使いのコンピュータの中だけで

RocketWhisperの音声認識は、お使いのコンピュータの中だけで行われ、インターネットに接続していなくても使えます。音声データが外部に送信されることはありません。認識した文章が外部に送られるのは、お客様がオプションの「AI処理」でクラウドのサービスを選んだ場合だけです（6. ネットワーク通信）。

2. 収集しないデータ

本アプリは以下のデータを一切収集しません：

  • 音声データ（録音された音声）
  • 音声認識結果（テキストデータ）
  • 個人を特定できる情報（氏名、メールアドレス、IPアドレス等）
  • 使用状況のテレメトリデータ
  • 位置情報
  • デバイス識別情報

3. ローカル処理について

本アプリの音声認識機能は、OpenAI Whisperモデルをローカルで実行することで実現されています。

処理の流れ

  1. マイクから音声を録音、または音声ファイルを読み込み
  2. お使いのコンピュータ上でWhisperモデルが音声を解析
  3. 認識結果がアプリ内に表示

この処理の全過程において、データがインターネットを経由することはありません。

4. ローカルに保存されるデータ

本アプリは、ユーザー体験の向上のために以下のデータをお使いのコンピュータにローカル保存します：

設定情報（Windowsレジストリ）

  • 選択されたWhisperモデル
  • 認識言語設定
  • マイクデバイス設定
  • ホットキー設定
  • 自動コピー/貼り付け設定
  • ウィンドウ位置・サイズ
  • AI処理の API キー（Windows の機能で暗号化して保存）

保存場所: HKEY_CURRENT_USER\Software\Mojosoft\RocketWhisper

認識履歴（ローカルファイル）

  • 過去の認識結果テキスト
  • 認識日時
  • ソース情報（マイク/ファイル）

保存場所: %APPDATA%\RocketWhisper\history.json

専門用語・修正ルール

  • 登録された専門用語
  • 誤認識修正ルール
  • 音声コマンド設定

保存場所: %APPDATA%\RocketWhisper\

Whisperモデルファイル

  • ダウンロードしたWhisperモデル（.bin形式）

保存場所: %PUBLIC%\Documents\RocketWhisper\Models\（このパソコンのすべてのユーザーで共有）

診断ログ

  • 起動や認識にかかった時間、エラーの種類などの動作の記録（14 日分）
  • 音声・認識した文章・API キーは記録しません

保存場所: %APPDATA%\RocketWhisper\logs\

データの削除方法

これらのローカルデータは、以下の手順で完全に削除できます：

  1. RocketWhisperをアンインストール
  2. %APPDATA%\RocketWhisper フォルダを削除
  3. %PUBLIC%\Documents\RocketWhisper フォルダ（ダウンロードしたモデル）を削除
  4. レジストリエディタで HKEY_CURRENT_USER\Software\Mojosoft\RocketWhisper を削除（任意）

5. 第三者への提供

当社は、本アプリで扱うデータ（音声・認識した文章・設定など）を受け取ることはなく、第三者に提供することもありません。なお、オプションの AI 処理でクラウドのサービスを選んだ場合は、認識した文章がお客様の設定したプロバイダ（OpenAI・Anthropic・Google・Groq など）に直接送られ、各社のプライバシーポリシーに従って扱われます。

6. ネットワーク通信

本アプリがネットワーク通信を行うのは、以下の場合のみです：

Whisperモデルのダウンロード

  • 接続先: Hugging Face（モデルホスティングサービス）
  • 目的: 音声認識モデルファイルのダウンロード
  • 送信データ: なし（ダウンロードリクエストのみ）

モデルをダウンロード後は、完全にオフラインで動作します。

AI処理機能（オプション）

AI処理機能を使用する場合、選択したAIプロバイダによってデータの送信先が異なります：

  • ローカルLLM（LM Studio / Ollama）: データは外部に送信されません（完全オフライン）
  • クラウドAPI（OpenAI / Anthropic / Groq / Gemini）: 認識結果テキストが各プロバイダのサーバーに送信されます

💡 プライバシーを最優先にする場合

AI処理機能を使用する際、ローカルLLM（LM Studio や Ollama）を選択することで、認識結果を外部に送信することなく、完全オフラインでAI処理を行うことができます。

7. セキュリティ

本アプリはセキュリティを考慮して設計されています：

  • 音声認識はローカルで完結し、音声データをネットワークに送らないため、漏洩のリスクを最小限に抑えています
  • クラウドの AI サービスとの通信は暗号化（HTTPS）されます
  • AI 処理の API キーは、Windows の機能（DPAPI）で暗号化して保存します
  • 認識履歴はユーザーのローカルストレージにのみ保存

8. お子様のプライバシー

本アプリは年齢制限なく使用できますが、13歳未満のお子様が使用される場合は、保護者の監督のもとでご利用ください。本アプリはお子様の個人情報を収集しません。

9. プライバシーポリシーの変更

当社は、必要に応じて本プライバシーポリシーを更新することがあります。重要な変更がある場合は、本ページで通知します。定期的にご確認ください。

10. Microsoft Store 版について

  • 音声認識はすべてお使いの PC の中で行います。録音した音声や認識した文章を当社や第三者に送ることはありません。
  • AI 処理・AI コマンド・カスタム指示（RocketWhisper Pro の機能）は、お客様がご自身の API キーを設定し、プロバイダを選んだ場合に限り、処理する文章をそのプロバイダ（OpenAI、Anthropic、Google、Groq、またはお客様が指定したサーバー）に送ります。設定しなければ送信は行われません。
  • 音声検索（RocketWhisper Pro の機能）は、話した検索語でブラウザの検索ページを開くだけです。
  • 診断ログは PC の中にだけ保存します（音声・認識した文章・API キーは記録しません）。サポートのお問い合わせ時に、お客様の判断で送っていただく場合があります。
  • キーボードの監視は、録音の開始・終了に使う右 Alt キーと、設定したホットキーの押下の検出に限ります。入力した内容は記録しません。
  • RocketWhisper Pro の購入と決済は Microsoft が扱います。当社はお客様の支払い情報を受け取りません。
