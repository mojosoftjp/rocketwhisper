Privacy Policy

RocketWhisper is designed with your privacy as the top priority.

Last Updated: October 24, 2026

This Privacy Policy explains how data is handled in RocketWhisper (hereinafter "the App"). Mojosoft Co., Ltd. (hereinafter "we") designs and develops the App with user privacy protection as the highest priority.

1. Core Principle

Speech Recognition Stays on Your Computer

RocketWhisper recognizes speech only on your computer, and it works without an Internet connection. Audio data is never sent externally. Recognized text leaves your computer only if you choose a cloud service for the optional AI processing feature (see 6. Network Communication).

2. Data We Do Not Collect

The App does not collect any of the following data:

  • Audio data (recorded voice)
  • Speech recognition results (text data)
  • Personally identifiable information (name, email address, IP address, etc.)
  • Usage telemetry data
  • Location information
  • Device identification information

3. About Local Processing

The speech recognition feature is powered by running the OpenAI Whisper model locally.

Processing Flow

  1. Record audio from microphone, or load an audio file
  2. The Whisper model analyzes the audio on your computer
  3. Recognition results are displayed within the app

Throughout this entire process, no data passes through the Internet.

4. Data Stored Locally

The App stores the following data locally on your computer to improve user experience:

Settings (Windows Registry)

  • Selected Whisper model
  • Recognition language setting
  • Microphone device setting
  • Hotkey settings
  • Auto copy/paste settings
  • Window position and size
  • API keys for AI processing (stored encrypted with a Windows feature)

Location: HKEY_CURRENT_USER\Software\Mojosoft\RocketWhisper

Recognition History (Local File)

  • Past recognition result text
  • Recognition date and time
  • Source information (microphone/file)

Location: %APPDATA%\RocketWhisper\history.json

Custom Terms & Correction Rules

  • Registered custom terms
  • Misrecognition correction rules
  • Voice command settings

Location: %APPDATA%\RocketWhisper\

Whisper Model Files

  • Downloaded Whisper models (.bin format)

Location: %PUBLIC%\Documents\RocketWhisper\Models\ (shared by all users of this computer)

Diagnostic Logs

  • A record of how the app runs, such as start-up and recognition times and error types (kept for 14 days)
  • Audio, recognized text and API keys are never recorded

Location: %APPDATA%\RocketWhisper\logs\

How to Delete Data

You can completely delete all local data by following these steps:

  1. Uninstall RocketWhisper
  2. Delete the %APPDATA%\RocketWhisper folder
  3. Delete the %PUBLIC%\Documents\RocketWhisper folder (downloaded models)
  4. Optionally, delete HKEY_CURRENT_USER\Software\Mojosoft\RocketWhisper using Registry Editor

5. Third-Party Sharing

We never receive the data the App handles (audio, recognized text, settings and so on), and we do not share it with third parties. If you choose a cloud service for the optional AI processing feature, the recognized text is sent directly to the provider you set up (OpenAI, Anthropic, Google, Groq, etc.) and is handled under that provider's privacy policy.

6. Network Communication

The App communicates over the network only in the following cases:

Whisper Model Download

  • Connection: Hugging Face (model hosting service)
  • Purpose: Downloading speech recognition model files
  • Data sent: None (download request only)

After downloading a model, the App operates completely offline.

AI Processing Feature (Optional)

When using the AI processing feature, the destination of sent data varies depending on the selected AI provider:

  • Local LLM (LM Studio / Ollama): No data is sent externally (completely offline)
  • Cloud API (OpenAI / Anthropic / Groq / Gemini): Recognition result text is sent to each provider's servers

Tip: For maximum privacy

When using the AI processing feature, choosing a local LLM (LM Studio or Ollama) allows you to perform AI processing completely offline without sending recognition results externally.

7. Security

The App is designed with security in mind:

  • Speech recognition is completed locally and audio is never sent over the network, minimizing the risk of data leakage
  • Communication with cloud AI services is encrypted (HTTPS)
  • API keys for AI processing are stored encrypted with a Windows feature (DPAPI)
  • Recognition history is stored only in the user's local storage

8. Children's Privacy

The App can be used without age restrictions, but children under 13 should use it under parental supervision. The App does not collect children's personal information.

9. Changes to This Privacy Policy

We may update this Privacy Policy as needed. If there are significant changes, we will notify you on this page. Please check back periodically.

10. Microsoft Store Edition

  • All speech recognition runs on your PC. Recorded audio and recognized text are never sent to us or to third parties.
  • AI processing, AI Command and custom instructions (RocketWhisper Pro features) send the text being processed to the provider you choose (OpenAI, Anthropic, Google, Groq, or a server you specify) only after you enter your own API key and select that provider. Nothing is sent if you do not configure one.
  • Voice search (a RocketWhisper Pro feature) only opens a search page in your browser with the words you spoke.
  • Diagnostic logs are stored only on your PC (audio, recognized text and API keys are never recorded). You may choose to send them to us when contacting support.
  • Keyboard monitoring is limited to detecting the Right Alt key used to start and stop recording and the hotkeys you configure. What you type is never recorded.
  • Purchases and payments for RocketWhisper Pro are handled by Microsoft. We do not receive your payment information.

Summary

RocketWhisper fully protects your voice data and privacy. Speech recognition runs entirely on your computer and audio is never sent anywhere (only if you set up AI processing with your own API key is the text being processed sent to that provider). Use it with confidence.
